## Scope notes (honest limits of this release)

- Included: claim/receipt lifecycle for dispatch and instruction, in-loop
  escalation and instruction tools, in-place replanning during execution,
  cross-department handoff registry with delivery gating, acceptance coverage
  checks (criteria must be answered individually and carry evidence), cancelled
  dependency handling, child-session delivery ban, progress-panel chips and the
  pending-change banner.
- Not included (tracked as design work, not claimed fixed): push/SSE transport
  (panel still polls every 4 s), full automatic dispatch, independent reviewer,
  per-task budget/concurrency tuning, department duties encoded as data
  (contract v2 draft), checkpoint runtime semantics.
