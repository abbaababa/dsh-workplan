### P1-2 「已完成」组折叠后不可发现（自动展开已修，但默认态仍藏任务）

## 五、P2（3 项，后续迭代）

### P2-1 两组视觉仍缺区分（设计稿 §6.4 六项中 4 项未达）
- **证据**：全文件 `✓` 出现 **0 次**（已完成组无对勾）；`.dsh-wp-group-ring-arc` 只有一种 `--dsh-wp-done-ink`（`:409`），进行中组也是蓝环；两条导轨仍是 `linear-gradient`（`:391-392`，深色 `:655-656`）。
- **影响**：组别区分仍主要靠文字与折叠状态，「精美」维度停在能看。
- **最小改动**：3 行 CSS + 1 个字符：按 `group` 给环换色（live 用 `--dsh-wp-active-text`）；导轨改实色；已完成组标题前加 `✓`（`aria-hidden`）。
- **验收**：渲染树中出现 2 种 `stroke` 值；`✓` 计数 ≥1；导轨 `background-image` 为 `none`。

### P2-2 最小字号 11px 与图例缺数量
- **证据**：环中心百分比 `font-size: 11px`（`:410`），为面板最小字号；环形图 `legend.labels` 只有标签无数量（`:1467`）。
- **影响**：292px 窄栏下百分比偏小；图例看不出 2/4 这类计数，需靠 aria。
- **最小改动**：11px → 12px；legend 的 `generateLabels` 或 label 文案拼上数量（已有 aria 计数可直接复用）。
- **验收**：全面板 `font-size` 最小值 ≥12px；图例文本含数字。

### P2-3 `color-mix` 兼容性无兜底
- **证据**：`:362-363` 依赖 `color-mix()`；Safari <16.2 / Chrome <111 不支持时该声明在计算值阶段失效，`color` 回退为继承色。
- **影响**：旧浏览器不崩，但状态色丢失（文字仍可读，方向安全）；不确认用户浏览器版本，故列 P2。
- **最小改动**：在 `color-mix` 声明前加一行普通 `color: var(--dsw-alias-label-primary)` 兜底（同选择器内），或 `@supports not (color: color-mix(in srgb, red, blue))` 分支。
- **验收**：目标浏览器 computed color 非空且对比度 ≥4.5；不合规浏览器下不出现透明/继承异常。
